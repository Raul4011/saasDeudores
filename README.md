# App sencilla para controlar deudores (venta de ropa)

Aplicación web simple (sin backend) para:

- Registrar personas que te deben dinero.
- Ver cuánto debe cada persona.
- Registrar pagos para ir descontando la deuda.
- Guardar la información en el navegador (`localStorage`).

## Uso

1. Abre `index.html` en tu navegador.
2. Agrega nombre y monto adeudado.
3. Registra pagos en cada deudor.
4. Revisa el historial de pagos por persona.

## Nota

Si cambias de navegador o borras los datos del navegador, se perderán los registros.
